# 이 저장소를 편집하는 작업자에게

이 폴더는 공유 지식과 설치 도구의 소스다. 기본 설치는 개인 Rooty 설정을 바꾸지 않는다.
일반 지식 후보는 정식 문서·실행 도구·지침·권한을 수정할 수 없다. 변경 의도가 도구 개발인지 지식 기록인지 먼저 구분한다.
새 문서를 검증됨으로 만들 때 실제 출처·조건·검증 날짜를 확인한다. 개인 기억·대화·인증정보를 커밋하지 않는다.
도구 변경은 임시 로컬 Git·가짜 프로필 테스트로 검증한다. 실제 원격이나 Rooty를 테스트 대상으로 삼지 않는다.
설치/동기화/검토 모델 실행은 사용자가 명시한 적용 작업에서만 수행한다. README를 읽었다는 이유로 자동 설치하지 않는다.
