# main 모델 선택 — 2026-09-19

기본값은 **GPT-5.6 Sol / high / Standard(default)**로 정한다. main은 요구사항·설계·위임·통합을 맡고, 구현은 Luna가 수행하므로 반복되는 main 문맥의 단가를 낮추는 편이 유리하다고 판단했다. 어려운 미해결 쟁점은 기존 deep-reviewer(Astra/high)에 좁혀 전달한다. Sol/high와 Astra/low의 동일 작업 A/B 실행은 하지 않았으며, 아래 결론은 공식 단가와 현재 역할 구조에 근거한 기본 정책이다.

## 공식 비용과 해석

같은 처리 등급·문맥 구간에서 비교한다. API Standard 단문맥 가격이며, 단위는 100만 토큰당 USD다.

| 모델 | 비캐시 입력 | 캐시 입력 | 출력(추론 포함) |
|---|---:|---:|---:|
| GPT-5.6 Sol | 4 | 0.40 | 20 |
| GPT-6 Astra | 10 | 1 | 50 |

Sol의 각 토큰 단가는 Astra의 40%다. **같은 토큰 수라면 60% 저렴**하다는 뜻이며, 실제 완료 작업당 60% 절약을 보장하지 않는다. high/low는 토큰 수를 고정하지 않고, 추론 토큰도 출력 단가로 과금된다. 재시도·도구 결과·하위 에이전트·추가 검토를 포함한 완료 비용으로 비교해야 한다. [Sol 모델](https://developers.openai.com/api/docs/models/gpt-5.6-sol), [Astra 모델](https://developers.openai.com/api/docs/models/gpt-6-astra), [추론 토큰 과금](https://developers.openai.com/api/docs/guides/reasoning).

비캐시 입력 I, 캐시 입력 C, 추론을 포함한 출력 O를 누적하면, 동일 단문맥/Standard 조건에서 비용은 다음과 같다(별도 캐시 쓰기·도구 요금 제외).

- Sol: `(4I + 0.4C + 20O) / 1,000,000`
- Astra: `(10I + C + 50O) / 1,000,000`
- W = I + 0.1C + 5O라고 두면 Sol의 W가 Astra의 **2.5배 미만**일 때 Sol이 저렴하다. 단순 총 토큰 수가 아니라 과금 비중을 반영한 비교다.

예를 들어 Astra가 비캐시 입력 100,000과 출력 10,000을 쓰면 $1.50이다. Sol은 같은 입력과 출력에서 $0.60이며, 입력이 같다면 출력 55,000까지 $1.50 이하다. 이 예는 계산 예시이며 실제 high/low 소비량 측정값이 아니다.

ChatGPT/Codex의 공개 크레딧 표도 입력·캐시 입력·출력 순서로 Sol 100/10/500, Astra 250/25/1,250으로 동일한 2.5배 비율이다. 구독 한도는 고정 메시지 수가 아니며 실제 사용량·계약에 따라 다르다. Sol의 현재 프로모션 가격은 최소 2026-11-21까지라고 안내하므로 이후 재확인한다. [공식 크레딧·한도](https://learn.chatgpt.com/docs/pricing).

## Fast 기본값 해제

`service_tier = "default"`로 변경했다. Fast는 지능 향상 설정이 아니라 처리 속도와 비용의 선택이다. 공식 문서상 GPT-5.6의 ChatGPT Fast는 Standard 대비 2.5배 크레딧, API Priority/Fast는 2배 토큰 단가다. 계정 과금 방식이 다르므로 이 배수를 섞어 계산하지 않는다. [속도·과금 기준](https://learn.chatgpt.com/docs/agent-configuration/speed).

## 재평가 방법

`conf-sol-high`는 기존 프로필 이름 호환용으로 보존하고 `conf-astra-low`를 비교 프로필로 제공한다. 설치 도구가 생성한 프로필은 main 모델·추론만 다르고 하위 역할·권한·처리 등급은 같다.

비슷한 난이도의 실제 작업을 같은 기준 커밋·완료 조건·캐시 조건으로 비교한다. 완료 여부와 회귀 통과를 먼저 확인하고, main 및 하위의 누적 입력/캐시 입력/출력, 실패 재시도, 실제 비용, 소요 시간을 기록한다. 실제 출력 사용량에 포함된 추론 토큰을 다시 더하지 않는다. Astra가 재작업을 줄여 완료당 비용까지 낮춘다는 근거가 쌓이면 기본값을 재검토한다. 단가만으로 어느 쪽이 더 적은 원시 토큰을 쓰는지는 판단하지 않는다.

이번 설정 변경은 새 세션의 기본값이며 이미 실행 중인 main의 모델을 바꾸었다는 뜻은 아니다.
